# AI Resume Analyzer & Job Recommendation System

## Overview

The AI Resume Analyzer is a machine-learning-based application
that analyzes resumes and recommends suitable job roles.

## Features

- Resume PDF parsing
- Text cleaning
- Skill extraction
- Job-role recommendation
- TF-IDF based matching
- Cosine similarity
- Skill gap analysis
- Personalized learning roadmap
- Streamlit web interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- PyPDF
- Python-docx

## Project Workflow

Resume Upload
→ Resume Parsing
→ Text Cleaning
→ Skill Extraction
→ Job Matching
→ Skill Gap Analysis
→ Learning Roadmap
